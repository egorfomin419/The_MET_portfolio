# THE MET — Museum Landing Page

A responsive landing page for THE MET museum website. The project showcases current exhibitions, upcoming events, and museum information through a clean, modern layout with an interactive header, image galleries and a mobile-friendly navigation menu.

## Live Preview

Experience the live website: [THE MET Demo](https://egorfomin419.github.io/The_MET_portfolio/)

 ## Design Reference
  Figma: [link](https://www.figma.com/design/lSR1m42L9YwzQwzzxKwHpw/THE-MET?node-id=8590-29&p=f&t=6eD5AI3il4JuKXZe-0)

## Technologies Used

- **HTML5** — page markup
- **SCSS** — styling, organized into partials (blocks/utils)
- **JavaScript** — interactivity (burger menu, phone dropdown, etc.)
- **Parcel** — bundler and dev server
- **ESLint / Stylelint** — code quality and formatting
- **GitHub Pages** — hosting and deployment

## Getting Started

1. Clone the repository:

```
git clone https://github.com/egorfomin419/The_MET_portfolio.git
cd The_MET_portfolio
```

2. Install dependencies:

```
npm install
```

3. Run the project locally:

```
npm start
```

## Features

- **Responsive Design**: layout adapts to different screen sizes, from mobile to desktop.
- **Interactive Header**: burger menu and phone number dropdown with smooth open/close behavior.
- **Image Galleries**: sections for current exhibitions ("Now on view") and online collection highlights.
- **Custom Typography**: Google Fonts (Cinzel, Roboto) for a museum-style aesthetic.
- **Optimized Assets**: images and icons organized for fast loading.
